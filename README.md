# Tachograph Reminder Bot

Telegram-бот, який нагадує водію про режим праці та відпочинку за Регламентом (ЄС) 561/2006 / AETR.

> ⚠️ Розрахунок спрощений, для довідки. Він не замінює тахограф і не є юридичною консультацією.

## Як користуватись

Водій натискає кнопку щоразу, коли змінює режим:

| Кнопка | Команда | Що означає |
|---|---|---|
| 🚛 Їду | `/drive` | почав кермувати |
| 🔧 Інша робота | `/work` | завантаження, огляд, документи — **не** перерва |
| 🛑 Відпочинок | `/stop` | перерва або відпочинок |
| 📊 Статус | `/status` | скільки ще можна їхати, дедлайни |
| 📜 Історія | `/history` | останні записи |

Також є `/tz Europe/Warsaw` (часовий пояс водія), `/lang` (uk/en) і `/help`.
Якщо водій забув натиснути вчасно, можна вказати, скільки хвилин тому це було: `/stop 10`.

## Що рахує бот

- **Безперервне водіння** — 4 год 30 хв. Лічильник обнуляє лише перерва 45 хв або 15 + 30 хв (саме в такому порядку). Коротка зупинка чи інша робота лічильник **не** обнуляють.
- **Денне водіння** — 9 год, подовження до 10 год не більше 2 разів на тиждень.
- **Денний відпочинок** — 11 год (скорочений 9 год — до 3 разів між тижневими відпочинками; розділений 3 + 9 год). Його треба почати так, щоб він закінчився протягом 24 год від початку зміни.
- **Тижневе водіння** — 56 год, за два тижні поспіль — 90 год. Тиждень рахується як у тахографі: з понеділка 00:00 UTC.
- **Тижневий відпочинок** — не пізніше ніж через 6 діб після попереднього.

Бот сам надсилає попередження:
- за 30 хв до кожного ліміту і коли ліміт вичерпано;
- коли перерва виконана і можна їхати далі;
- коли 11-годинний відпочинок завершено (це повідомлення приходить без звуку).

Кожне попередження надсилається один раз. Якщо бот був вимкнений, після перезапуску водій отримає лише останнє актуальне попередження, а не всю пачку.

## Структура

```
bot.py       — запуск, реєстрація обробників і фонових задач
config.py    — налаштування зі змінних середовища
rules.py     — правила 561/2006 (без Telegram і БД, покриті тестами)
db.py        — SQLite: водії, історія періодів, надіслані попередження
texts.py     — тексти uk/en, форматування тривалості й часу
views.py     — тексти статусу, історії, попереджень
handlers.py  — команди та кнопки
jobs.py      — фонова перевірка раз на хвилину
tests/       — тести правил і сценаріїв роботи бота
```

## Запуск локально

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен_від_BotFather"
python3 bot.py
```

Тести:

```bash
python3 -m unittest discover -s tests -v
```

## Змінні середовища

| Змінна | За замовчуванням | Опис |
|---|---|---|
| `BOT_TOKEN` | — | токен бота (обов'язково) |
| `DB_PATH` | `tachograph.db` | шлях до файлу SQLite |
| `DEFAULT_TZ` | значення `TZ`, інакше `Europe/Kyiv` | часовий пояс для нових водіїв |
| `CHECK_INTERVAL_SEC` | `60` | як часто перевіряти таймери |

## Railway

- Підключіть **Volume** (наприклад, з точкою монтування `/data`) і задайте `DB_PATH=/data/tachograph.db`. Без цього база стирається при кожному деплої.
- Потрібна рівно **одна** репліка: дві копії бота з одним токеном конфліктують при отриманні оновлень.
- Команда запуску задана в `railway.json`: `python bot.py`.

Стара база (з попередньої версії бота) мігрує автоматично.
